# 🎧 Scream Audio Monitoring Project

📄 Project page: **[Integrated Audio Monitoring System — Scream Ecosystem](https://zirize.github.io/scream-audio-monitoring/)** · More projects: **[zirize.github.io](https://zirize.github.io/)**

This project focuses on building an **Integrated Audio Monitoring System** that aggregates audio alerts and system sounds from multiple devices (Windows, Linux, and Embedded) over a local network (LAN) to a central monitoring station.

## 🚀 Overview

In environments like smart factories, data centers, or large workspaces, monitoring the status of numerous devices through sound is critical. This project utilizes the **Scream protocol** to capture and stream PCM audio via UDP multicast, eliminating the need for physical audio cables.

### Key Components

- **[duncanthrax/scream](https://github.com/duncanthrax/scream)**: Virtual network sound card for Windows.
- **[zirize/pipewire-scream](https://github.com/zirize/pipewire-scream)**: PipeWire module for Linux systems to stream audio over the network.
- **[zirize/screamplay](https://github.com/zirize/screamplay)**: CLI utility for playing back audio files (WAV, MP3, etc.) directly into the Scream network with intelligent resampling.
